# REST API Documentation for Frontend Integration

Welcome to the REST API documentation for **Travel Without Limits** (`youngover60.com`). This document is prepared for frontend developers integrating custom clients, templates, or widgets with the platform's backend services.

## Base Configuration

All API requests are relative to the production base URL:
```env
https://youngover60.com
```

### Response Format
All API responses return JSON format with a standard UTF-8 charset:
* Header: `Content-Type: application/json; charset=UTF-8`
* Format: Every response contains a boolean `success` flag. On failure, an `error` string is returned.

---

## Security & Authentication

State-changing requests (`POST` methods) require authentication check and CSRF protection to prevent unauthorized command execution.

### 1. CSRF Token Protection
Any `POST` request (Contact form submission, Newsletter subscription, Media upload) must submit a `csrf_token` parameter matching the user's current session token.

#### How to obtain the CSRF Token:
* **Option A (HTML DOM - Recommended)**: Extract the token from the hidden input generated by the backend helper `Auth::csrfInput()` in forms:
  ```javascript
  const csrfToken = document.querySelector('input[name="csrf_token"]').value;
  ```
* **Option B (Template Injection)**: If writing custom inline scripts inside PHP pages, render the token directly:
  ```javascript
  const csrfToken = '<?php echo csrfToken(); ?>';
  ```

### 2. Session Authorization
The `/api/upload` endpoint requires active administrator privileges.
* The backend tracks authentication via the PHP Session Cookie (`PHPSESSID`).
* Frontend scripts making AJAX requests must include credentials (e.g. `credentials: 'same-origin'` or `withCredentials: true` in axios) to ensure session cookies are sent with requests.

### 1. GET `/api/posts`

Retrieves a paginated list of published articles, podcasts, or stories. Used primarily for search inputs, grid filtering, and dynamic content streams.

#### Query Parameters

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `categoryId` | `string` | No | *None* | Filters posts by Category ID or slug (supports both English/Arabic slugs). |
| `search` | `string` | No | *None* | Text search query. Matches title, excerpt, and content fields (searches fields matching the active session language). |
| `limit` | `integer` | No | `10` | Number of items to return per page. |
| `page` | `integer` | No | `1` | The page number to fetch for pagination. |

#### Example Request
```http
GET https://youngover60.com/api/posts?categoryId=destinations&limit=3&page=1 HTTP/1.1
Accept: application/json
```

### 2. POST `/api/contact`

Submits an interactive contact or message inquiry, inserts it into the `contact_submissions` table, and delivers a notification email to the administrator.

#### Request Headers
```http
Content-Type: application/x-www-form-urlencoded
```

#### Payload Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `csrf_token` | `string` | **Yes** | CSRF validation token associated with active session. |
| `name` | `string` | **Yes** | Full name of the user sending the message. |
| `email` | `string` | **Yes** | Sender's email address (validated backend format). |
| `phone` | `string` | **Yes** | Sender's telephone or mobile number. |
| `message` | `string` | **Yes** | Body content of the inquiry. |

#### Example Fetch Request
```javascript
const formData = new URLSearchParams();
formData.append('csrf_token', document.querySelector('input[name="csrf_token"]').value);
formData.append('name', 'Jane Doe');
formData.append('email', 'jane.doe@example.com');
formData.append('phone', '+1555123456');
formData.append('message', 'Hello! I would love to write a travel blog post.');

fetch('https://youngover60.com/api/contact', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/x-www-form-urlencoded'
  },
  body: formData
})
.then(res => res.json())
.then(data => console.log(data));
```

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "message": "Message submitted successfully."
}
```

#### Error Responses
* **Missing Fields (`200 OK`)**
  ```json
  {
    "success": false,
    "error": "Please fill in all required fields."
  }
  ```
* **Invalid Email Format (`200 OK`)**
  ```json
  {
    "success": false,
    "error": "Please provide a valid email address."
  }
  ```
* **CSRF Token Mismatch (`403 Forbidden`)**
  ```json
  {
    "success": false,
    "error": "Security validation mismatch."
  }
  ```
* **Invalid Request Method (`405 Method Not Allowed`)**
  ```json
  {
    "success": false,
    "error": "Method not allowed."
  }
  ```

### 3. POST `/api/newsletter`

Adds an email subscriber to the mailing list. If the email already exists in the `newsletters` table, returns a success state indicating they are already registered.

#### Request Headers
```http
Content-Type: application/x-www-form-urlencoded
```

#### Payload Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `csrf_token` | `string` | **Yes** | CSRF validation token associated with active session. |
| `email` | `string` | **Yes** | Email address to register (validated backend format). |

#### Success Responses (`200 OK`)
* **New Subscription**:
  ```json
  {
    "success": true,
    "message": "Thank you for subscribing!"
  }
  ```
* **Existing Subscription**:
  ```json
  {
    "success": true,
    "message": "You are already subscribed."
  }
  ```

#### Error Responses
* **CSRF Failure (`403 Forbidden`)**:
  ```json
  {
    "success": false,
    "error": "Security token invalid."
  }
  ```
* **Validation Failure (`200 OK`)**:
  ```json
  {
    "success": false,
    "error": "Invalid email address format."
  }
  ```

### 4. POST `/api/upload`

An administrative endpoint for uploading and optimizing files (Images, Audio, and Video). 

> [!WARNING]
> This endpoint checks `Auth::check()` and will reject any unauthorized attempts with a `401 Unauthorized` response.

#### Request Headers
```http
Content-Type: multipart/form-data
```

#### Query Parameters

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `type` | `string` | No | `image` | Explicit upload stream filter: `audio` or `video`. If blank, it auto-detects from the file's mimetype. |

#### Payload Parameters (Multipart Form Data)

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `csrf_token` | `string` | **Yes** | CSRF validation token associated with the session. |
| `file` | `file blob` | **Yes** | The raw binary file payload. |

#### File Constraint Reference Table

| Target Type | Max Allowed Size | Allowed Mime-Types | Optimization Applied |
| :--- | :--- | :--- | :--- |
| **Image** | **2 MB** | `image/jpeg`, `image/png`, `image/webp`, `image/jpg`, `image/x-icon`, `image/vnd.microsoft.icon`, `image/svg+xml`, `image/gif` | Yes (Dynamic GD Compression & Optimization) |
| **Audio** | **50 MB** | `audio/mpeg`, `audio/mp3`, `audio/wav`, `audio/x-wav`, `audio/ogg`, `audio/aac` | None (Direct Storage) |
| **Video** | **50 MB** | `video/mp4`, `video/webm`, `video/ogg`, `video/quicktime`, `video/x-matroska`, `video/avi`, `video/mpeg` | None (Direct Storage) |

#### Example Javascript File Upload Code
```javascript
const fileInput = document.querySelector('input[type="file"]');
const formData = new FormData();
formData.append('csrf_token', 'your_csrf_token_here');
formData.append('file', fileInput.files[0]);

// Query string type optional, e.g., ?type=audio or ?type=video
fetch('https://youngover60.com/api/upload?type=video', {
  method: 'POST',
  body: formData
})
.then(res => res.json())
.then(data => {
  if (data.success) {
    console.log('Uploaded filename: ', data.filename);
    console.log('Absolute URL: ', data.url);
    console.log('Relative URL: ', data.relativeUrl);
  } else {
    console.error('Error: ', data.error);
  }
});
```

#### Success Response (`200 OK`)
```json
{
  "success": true,
  "url": "https://youngover60.com/uploads/2f5b8a6e_1716254820.mp4",
  "relativeUrl": "/uploads/2f5b8a6e_1716254820.mp4",
  "filename": "2f5b8a6e_1716254820.mp4",
  "message": "Video uploaded successfully."
}
```

#### Error Responses
* **Unauthorized Access (`401 Unauthorized`)**:
  ```json
  {
    "success": false,
    "error": "Unauthorized action. Please log in first."
  }
  ```
* **CSRF Verification Failure (`403 Forbidden`)**:
  ```json
  {
    "success": false,
    "error": "CSRF verification failed."
  }
  ```
* **Size Constraint Exceeded (`200 OK`)**:
  ```json
  {
    "success": false,
    "error": "Exceeded 50MB audio size limit."
  }
  ```
* **Invalid File Format (`200 OK`)**:
  ```json
  {
    "success": false,
    "error": "Invalid file type. Only JPG, PNG, WebP, ICO, SVG, and GIF images are allowed."
  }
  ```
